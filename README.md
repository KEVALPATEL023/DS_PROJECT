# DS_PROJECT
Problem Statement:
Create an inventory management system for a small store using arrays in C. The system should allow
the store owner to perform the following operations on the inventory:
I. Insertion: Add a new item to the inventory.
II. Deletion: Remove an item from the inventory.
III. Searching: Search for an item by its ID.
IV. Updating: Update the quantity or price of an item.
V. Traversal: Display all items in the inventory.
